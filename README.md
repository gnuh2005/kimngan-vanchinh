## 📖 Giới thiệu

Kim Ngân & Văn Chịnh là website thiệp cưới trực tuyến được xây dựng nhằm mang đến một cách thức gửi lời mời tham dự lễ cưới hiện đại và tiện lợi.

Website giúp khách mời dễ dàng xem thông tin cô dâu, chú rể, ngày tổ chức hôn lễ, hình ảnh cưới và địa điểm tổ chức thông qua một đường link duy nhất.

## ✨ Tính năng

- **Thông tin cô dâu và chú rể:** Giới thiệu thông tin và hình ảnh của hai nhân vật chính.
- **Thông tin gia đình:** Hiển thị thông tin hai bên gia đình.
- **Album ảnh cưới:** Trưng bày những khoảnh khắc đáng nhớ.
- **Lịch cưới:** Hiển thị ngày tổ chức hôn lễ.
- **Đếm ngược ngày cưới:** Theo dõi thời gian đến ngày trọng đại.
- **Thông tin sự kiện:** Cung cấp thời gian và địa điểm tổ chức lễ cưới.
- **Bản đồ chỉ đường:** Hỗ trợ khách mời tìm kiếm địa điểm tổ chức.
- **Giao diện Responsive:** Tương thích với điện thoại, máy tính bảng và máy tính.

## 🚀 Cài đặt dự án

**Bước 1: Clone repository**

```bash
git clone https://github.com/gnuh2005/kimngan-vanchinh.git
```

**Bước 2: Di chuyển vào thư mục dự án**

```bash
cd kimngan-vanchinh
```

**Bước 3: Khởi chạy website**

Mở file `index.html` bằng trình duyệt hoặc sử dụng tiện ích Live Server trong Visual Studio Code.

## 🌐 Triển khai website

Dự án được triển khai thông qua GitHub Pages.

Các bước thực hiện:

1. Đẩy source code lên GitHub.
2. Truy cập repository trên GitHub.
3. Chọn **Settings** → **Pages**.
4. Tại mục Build and deployment, chọn Deploy from a branch.
5. Chọn branch `main` và thư mục `/root`.
6. Nhấn Save để hoàn tất.
7. Truy cập đường dẫn website sau khi GitHub Pages triển khai thành công.
